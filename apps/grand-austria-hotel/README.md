# 奥地利大饭店 · 好友联机版

按 **2021 基础版**规则实现，提供本地试玩和好友公网联机。公网使用游戏专用 Vercel API 与 Neon 数据库；博客入口为 `https://antonalia.github.io/friends-hotel/`，也可从站内搜索进入。访问密码单独保存在本机私有文件中，不进入源码或静态页面。

## 从博客搜索进入（推荐）

1. 像平常一样启动 `D:\antonalia.github.io\start-admin.bat` 或 `run-hexo-server.bat`。
2. 打开博客首页 `http://localhost:4000/`，点击搜索，输入“奥地利大饭店”。
3. 点击“奥地利大饭店 · 好友联机”，进入 `http://localhost:4000/friends-hotel/`。
4. 首次由你在电脑上设置一次访问密码；之后各玩家输入密码和自己的昵称进入。
5. 想一个人查看画面和操作，可点击“单人画面测试”。登录后直接进入，不需要建房或等待好友。

游戏接口随Hexo本地服务一起加载，不需要另开4173端口。入口只追加到搜索索引，不加入首页文章、归档、分类或导航。密码由服务端验证。

## 单人画面测试

也可直接访问 `http://localhost:4000/friends-hotel/?preview=1`，登录后进入。测试使用一人控制两席的示例模式，自动跟随当前回合；可以手动切换安娜/约瑟夫的视角，选择“饭店营业中 / 新局开场 / 终局计分”，更换经典夜面/不同日面，并随时重置。

取骰、上菜、入住、员工和计分使用同一套纯规则引擎。测试状态仅在当前页面内存中，不创建好友房间、不修改正式存档；刷新会恢复示例。退出后保留原来的登录身份。

美术方向、两张原创插画的路径及生成提示词见 `docs/ART_DIRECTION.md`。人物肖像按四类客人共用，卡牌仍保留每位客人自己的订单、分数与奖励。

博客模式的密码和对局存放在本项目 `.private/blog-state.json`；独立试玩仍用 `.private/local-state.json`。两个模式独立，避免两个进程同时写同一存档。不会自动迁移或覆盖已有存档。

本地博客仍只监听电脑回环地址。不要为了iPad试玩把博客管理后台暴露到局域网；同Wi-Fi试玩可使用下面的独立游戏启动方式，公网版本后续配置专用API。

## 在电脑上开始

需要 Node.js 22 或以上。当前电脑已具备。

1. 双击 `启动本地试玩.cmd`，保留终端窗口。
2. 浏览器打开 `http://localhost:4173/`。
3. 首次从本机设置一个至少 12 字符的好友访问密码。实际密码由你自己设置，项目没有默认正式密码。
4. 输入昵称和密码进入，创建房间。所有好友进入后由房主开始。

也可以在此目录运行：

```powershell
node server.mjs
```

当前本地模式无需 Neon、Vercel 或其他账号。服务端将存档、密码哈希和会话保存到忽略提交的 `.private/local-state.json`。不要把该目录上传或分享。停止服务后，再次启动可继续；同一存档只启动一个服务进程。

## iPad 与电脑在同一 Wi-Fi 玩

1. 先用本机 `localhost` 完成访问密码设置。
2. 关闭原本的服务终端，双击 `启动局域网试玩.cmd`。
3. 终端会打印 `LAN · http://电脑局域网地址:4173`。iPad 用 Safari 打开该地址。
4. 好友各自输入密码和昵称，再输入同一个房间码。

仅在可信的局域网测试。此模式使用 HTTP；以后公网发布使用 HTTPS。若 Windows 弹出防火墙提示，只允许你实际使用的私人网络。项目不会自动修改防火墙、路由器或公网端口。

同一电脑测试多人，可分别用两个浏览器，或打开 `http://localhost:4173/?profile=player2`。不同 `profile` 使用独立玩家身份。

## 怎么操作

- 开局逆序选一位免费客人，再按点击顺序准备最多三间房。可直接选择底层前三间。
- 迎客是可选步骤，必须在本回合骰子主动作之前。自己的回合可以先入住腾出咖啡厅位置。
- 取骰后左侧会显示需要你处理的效果。先处理完当前效果，再继续额外动作。
- 获得食饮时可以直接分配给客人；其余放厨房。之后移动厨房库存需要上菜动作。
- 准备多个房间、移除多间空房时，顺序按你点击的先后。每一步都由服务器检查。
- 每轮员工位于“已雇员工”。手牌仅自己可见，位于左侧“我的员工手牌”。
- 暂时跳过不会消耗号码，但该骰池中自己的后续号码也暂缓；所有其他玩家完成或跳过后重掷。
- 第3、5、7轮皇帝计分后退对应格数；落0受罚，1/2无事，至少3领奖。
- 暂时离开页面会暂停查询；回来恢复。若主动退出玩家身份，原会话会注销；换设备请先导出重连文件。
