# 参考资料与资源边界

玩法依据Lookout Games《Grand Austria Hotel》2021基础规则；卡牌机械事实与酒店布局结合官方说明书及Yucata公开规则、卡图交叉核对。规则引擎、接口和页面由本项目独立编写。

`reference/research-notes.md`记录了逐项核验、旧版差异与其他开源参考。未复用Yucata实现代码、界面样式或游戏美术；下载的规则PDF和卡图仅留在忽略提交的资料目录，不进入`public/`、`dist/`或博客。

本版页面的饭店入口与四类客人肖像由内置imagegen原创生成，路径与提示词见`docs/ART_DIRECTION.md`；窗框棋盘、纸质卡牌排版和SVG图标为本项目编写。没有复用原作或线上版本的美术资源。Grand Austria Hotel名称及原作内容属于各自权利人；本地项目不代表官方产品或获得授权的发行版本。
