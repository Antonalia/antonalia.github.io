# 本地验收

## 自动验证

运行 `node --test test/*.test.mjs`。测试覆盖：

- 牌库数量、卡号、五版面20格/10组、真实评分表。
- 开局与蛇形号码、pass/重掷、六动作、增强、员工按实体骰面触发。
- 食饮直接分配与付费上菜、颜色限制、入住腾位与组奖只领一次。
- 56位客人的完整奖励链、48名员工的雇用/立即/每轮结算、全部皇帝奖励和处罚、全部终局评分器。
- E.Gizia、会议经理、花园员工、管理员、男楼层管家、接线员等特殊规则。
- 2/3/4人 × 夜/日版面，每种5局完整七轮流程。
- 真实HTTP客户端登录、创建/加入房间、成员权限、开始、准备、同步、刷新、重复请求与同版本并发。
- 密码初始化/错误密码/注销、来源限制、静态文件边界、限流和持久化重新加载。

## 浏览器手动验收

本机正式存档的初始密码由用户自己设置。隔离UI测试服务 `test/preview.mjs` 仅使用内存和明确测试密码，不访问正式存档或Neon。

1. 两个独立玩家进入，创建/加入同一房间，房主开始。
2. 分别选择起始客人，按顺序准备房间。
3. 正式回合取骰，填写效果数量，确认处理，结束回合；另一玩家收到新状态。
4. 刷新浏览器，从“我的对局”回到同一座位。
5. 查看对手酒店只出现公开信息和手牌数量。
6. 在1024与768宽度查看棋盘、左侧操作、数量输入和市场，确认不溢出。
