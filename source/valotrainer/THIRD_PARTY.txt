Original UI, all four modes, gunplay, player movement, buy menu, crosshair editor,
themes, sounds and local training history are retained. Site adaptations include
local dependency URLs, metadata, blog navigation, scoped offline caching, and
instant Chinese/English UI localization using mainland weapon terminology.
Language preference uses a separate storage key; original game data and profile
codes are preserved. Terminology sources are documented in docs/valotrainer.md
in the site repository.
This is an unofficial fan trainer, not affiliated with or endorsed by Riot Games.
VALORANT belongs to Riot Games. The project contains no client game assets.
